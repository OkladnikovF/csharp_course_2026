Это репозиторий где хранится базовый репозиторий и лабораторные работы. В main не нужно вносить изменения.
Нужно или форкнуть репозиторий и работать с форком. Или сделать отдельную ветку с которой вы будете работать.

## Как начать работу

### 1. Клонирование репозитория

git clone https://github.com/OkladnikovF/csharp_course_2026
cd csharp_course

### 2. Открытие в IDE

Откройте файл App.sln в:
- **Rider** (рекомендуется)
- **Visual Studio 2022+** 
- **VS Code** (с расширением C# Dev Kit)

## Как сдать работу

0. Создайте ветку с вашим именем: `git checkout -b ivan-ivanov`
1. Создайте ветку с вашим именем под лабораторную+задачу: `git checkout -b ivan-ivanov-lab1-task1`
2. Закоммитьте изменения: `git commit -m "Lab 1 implementation"`
3. Отправьте в репозиторий: `git push origin ivan-ivanov`
4. Создайте Pull Request'ы из веток с задачами в свою ветку
