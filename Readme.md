Это базовый репозиторий с лабораторными работами. В master не нужно вносить изменения.
**Нужно форкнуть репозиторий и работать с форком.**

Сами описания лабораторных находятся в папке Labs

## Как сдать работу

0. Сделайте форк репозитория
1. Создайте в форке ветку под лабораторную-задачу: `git checkout -b lab1-task1`
2. Закоммитьте изменения: `git commit -m "Lab 1 Task 1 implementation"`
3. Сделайте пуш ветки
4. Создайте Pull Request с задачей в master форка
